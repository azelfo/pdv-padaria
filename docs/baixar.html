Baixar instalador

Versão 1.1.15 · Windows

Seu computador é Windows 7 ou 8.1?

Nessas versões é preciso preparar o computador antes de instalar o PDV. Faça uma vez só, nesta ordem:

1
Atualização de segurança do Windows (KB4474419).
Sem ela o Windows 7 recusa os instaladores atuais da Microsoft, com a mensagem “certificado raiz que não é confiável”.
Baixar (Windows 64 bits) Windows 32 bits
Para saber se o seu é 32 ou 64 bits: Painel de Controle → Sistema, e veja em “Tipo de sistema”. Depois de instalar, reinicie o computador.
2
Instale o .NET Framework 4.8 (componente da Microsoft, cerca de 115 MB).
Baixar do site da Microsoft
Atenção: use apenas este botão. Não baixe o arquivo chamado “Language Pack” ou “Português do Brasil” — esse serve só para traduzir as mensagens e não instala o componente.
3
Reinicie o computador, se o instalador da Microsoft pedir.
4
Aí sim, baixe e instale o PDV no botão amarelo acima.
Antes de instalar
  • Windows 7 SP1, 8.1, 10 ou 11
  • Windows 8 “puro” não funciona — atualize gratuitamente para o 8.1
  • Peça ao Windows para executar como administrador
  • Se aparecer aviso do Windows Defender, clique em “Mais informações” e depois “Executar assim mesmo”
